# بيانات وقرارات مطلوبة قبل الإطلاق

لا ينبغي وصف النسخة الحالية بأنها جاهزة لاستقبال العملاء قبل استكمال الآتي:

- [ ] الاسم القانوني الرسمي والشعار، واعتماد الألوان الحالية والعلامة الكتابية المؤقتة.
- [ ] بلد ومدن العمل والخدمات المتاحة فعلاً وصلاحيات إصدار التراخيص والتقارير.
- [ ] مراجعة نطاق التصميم الإنشائي والكهروميكانيكي والتصميم الداخلي وإدارة التكلفة.
- [ ] رقم دولي رسمي لواتساب، وبريد رسمي، وعنوان، وساعات عمل، وروابط حسابات موثقة.
- [ ] مشاريع حقيقية: الاسم، الموقع المسموح، دور المؤسسة، النطاق، والصور وموافقات النشر.
- [ ] استبدال جميع التصورات التوضيحية في المعرض أو إبقاؤها موسومة بوضوح حسب قرار المؤسسة.
- [ ] بيانات الشركاء والعملاء والشهادات؛ القسم مخفي حالياً ولا توجد شعارات أو أرقام مختلقة.
- [ ] جهة استقبال الطلبات ومسؤول المتابعة وقناة webhook واختبار قبولها الفعلي.
- [ ] سياسة الاحتفاظ بالبيانات والحذف ومزودو التخزين وقناة طلبات الخصوصية؛ السياسة الحالية مسودة.
- [ ] نقل حد معدل الإرسال إلى مخزن مشترك عند استخدام بيئة serverless متعددة النسخ.
- [ ] الدومين وضبط `NEXT_PUBLIC_SITE_URL` وOpen Graph النهائي وبيانات المنظمة الموثقة فقط.
- [ ] اختبار الأداء الميداني بعد النشر؛ نتائج المختبر لا تثبت INP الميداني.
- [ ] اختبار قبول قانوني وتقني نهائي على أجهزة حقيقية وشبكة الجمهور المستهدفة.
