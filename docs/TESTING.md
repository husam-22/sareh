# سجل التحقق

تاريخ الاختبار: 11 نوفمبر 2026.

## البيئة

- Node.js 22.22.3 وnpm 10.9.8.
- Next.js 16.4.6، وضع production عبر `next start`.
- Chromium 153 headless في حاوية Linux، بعرض برمجي SwiftShader لـWebGL. هذه بيئة اختبار محلية وليست جهاز مستخدم حقيقياً.

## النتائج المنفذة

- `npm run typecheck`: ناجح.
- `npm run build`: ناجح؛ توليد 20 صفحة/مساراً ثابتاً بالإضافة إلى API التواصل الديناميكي.
- `npm audit --audit-level=high`: لا ثغرات معروفة في شجرة الاعتماديات وقت الفحص.
- `npm run test:smoke`: ناجح دون أخطاء Console جوهرية غير متعمدة.

شمل فحص المتصفح:

- تحميل `/` و`/services` وصفحة خدمة داخلية و`/projects` وصفحة مشروع و`/about` و`/contact` و`/privacy`.
- ظهور 404 العربية للمسار المفقود.
- تشغيل المشهد ثلاثي الأبعاد أثناء التمرير ولقطته الوسطى.
- التبويبات، أكورديون الخدمات، وتصفية المشاريع.
- الاختيار المسبق للخدمة من رابط التواصل، والتحقق من الحقول المطلوبة.
- إرسال نموذج صالح في وضع عدم الربط؛ ظهور «الطلب صالح، لكنه لم يُرسل» دون نجاح وهمي. استجابة 503 هنا متعمدة.
- قائمة الهاتف والإغلاق بـEscape.
- `prefers-reduced-motion` وإظهار المبنى والمحتوى دون رحلة التثبيت.
- تعطيل WebGL برمجياً وظهور الـposter مع بقاء العنوان والمحتوى.
- عدم وجود تمرير أفقي عند 360 و390 و768 و1024 و1440 و1920px.

اللقطات المحفوظة:

- `home-desktop.png`: الواجهة على 1440×1000.
- `home-mobile.png`: الواجهة على 390×844.
- `story-desktop.png`: مرحلة وسطى من المشهد على الكمبيوتر.

## قياس مختبري محدود

قياس واحد على production محلياً، 1440×1000، دون خنق شبكة أو CPU، وبعد مراقبتي LCP وCLS عبر Performance API:

- LCP: نحو **392ms**.
- CLS: نحو **0.0011**.

هذه الأرقام خاصة بالحاوية المحلية ولا تمثل شبكة الجمهور أو أجهزته، ولا تُستخدم لادعاء Core Web Vitals ميدانية. لم يُقس INP الميداني؛ يحتاج تفاعلات حقيقية أو بيانات RUM بعد النشر. لم يُعتمد ادعاء 60fps من تشغيل SwiftShader.

## ما يحتاج تحققاً لاحقاً

- أجهزة iOS وAndroid حقيقية، ومتصفحات Safari وFirefox وChrome المثبتة.
- التكبير النصي 200% وقارئات الشاشة ضمن خطة قبول الوصول النهائية.
- اختبار webhook الحقيقي وحالات قبوله ورفضه وانقطاعه بعد توفير جهة الاستقبال.
- Lighthouse مع خنق معلن، ثم RUM للـINP والمقاييس الميدانية بعد ربط الدومين.
- مراجعة بيانات المؤسسة والمشاريع وسياسة الخصوصية قبل الإطلاق العام.
